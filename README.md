# CargoFlow

CargoFlow is a cloud-based container trucking move management
platform developed as an end-to-end Cloud Database Management project.

## Business Problem

Container trucking operations often rely on fragmented email
communication for trucking requests, carrier assignments, pickup and
delivery updates, empty-container returns and supporting documentation.

CargoFlow aims to centralize this information and provide better
operational visibility.

## Main Objective

Design and develop an end-to-end cloud-based proof-of-concept platform
for collecting, storing, tracking, processing and analyzing container
trucking move information.

## Planned Technology Stack

- React
- Python / FastAPI
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Azure SQL Database
- Azure Blob Storage
- Azure Data Factory
- Docker
- Git / GitHub
- GitHub Actions
- Azure Monitor
